# Semantic Versioning

Format

MAJOR.MINOR.PATCH

Examples

v1.0.0

Initial stable release

v1.0.1

Bug fixes

v1.1.0

New features

v2.0.0

Major architectural changes

---

# Why Releases Matter

A release is a snapshot of the project at a specific point in time.

Even if development continues, the release remains unchanged.

Repository:

Continuously evolves

Release:

Stable historical version
